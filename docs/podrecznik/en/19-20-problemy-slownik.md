# Part III — Additional information

# 19. Troubleshooting

Each item: **symptom** → possible cause → what to do.

## 19.1 Account and access problems

- **The account confirmation email did not arrive** → the email went to spam or the address has
  a typo → check your spam folder; try creating the account again and choose [Resend email]
  — you can do this once an hour (→ 5.2).
- **"Confirm your email (link in inbox)." when signing in** → the account has not been confirmed →
  click the link in the "FAMILIADA — Confirm your account" email.
- **"Wrong email or password."** → the password or address is wrong → check upper and lower case in your password; you can
  also sign in with your username; if needed, use [Forgot password] (→ 5.7).
- **I cannot request another password reset** → you can request another email after an hour →
  wait for the countdown to finish and check your spam folder.
- **"Confirm you are human" appears** → several failed sign-in attempts → choose
  [Continue] and sign in again.
- **The data from a guest account is gone** → a guest account works only in one browser and is
  deleted after 5 days without a visit → to avoid this, save it as a regular account (→ 5.4).
- **"Not available for guest account"** → this feature requires an account → create an account and carry over the guest
  data (→ 5.4).

## 19.2 Problems with games and resources

- **[Play] is inactive** → the game is not ready or the poll is not closed → hover over
  the button to see the reason; what is missing is also shown under the game name (→ 6.2, 7.6).
- **I cannot edit a game** → the poll is open or stopped, the game is open somewhere
  else, or it is being played → abort or close the poll, close the other window with this game,
  end the game (→ 7.5).
- **"This game is open elsewhere."** → the game is open in another tab or on another
  device (editor, settings, poll, control panel) → close that window and try
  again.
- **An answer is not saved** → it contains characters the Display cannot show (for example emoji),
  or it is too long → remove those characters; an answer can have up to 17 characters (→ 7.3).
- **Importing a file does not work** → the file is not a game from the app or it is damaged → use a
  `.famgame` file exported from the app (→ 6.7); when importing text, check the format (→ 7.7).
- **I cannot edit a logo** → a game is being played or the game settings are open; on a phone, the editor
  is not available → end the game or close the settings; use a computer or tablet (→ 8.5).
- **"This database item is currently being edited…"** → someone else is editing this item → wait
  a moment and try again (→ 12.5).
- **[Send] is inactive** → the game has a poll (only a draft can be sent), comes from Community
  Games or from demo materials, or you have no friends → check what can be sent (→ 11.2).

## 19.3 Problems with polls and voting

- **A recipient did not get the invitation** → they have notifications turned off or the email went to
  spam → ask them to check their spam folder; a friend will also find the invitation in *Tasks* (→ 15.4);
  you can send [Remind] (→ 15.2).
- **"You have already voted in this poll"** → someone has already voted in this browser → everyone votes once.
- **A vote was not counted** → the voter left before the last question → answers
  are only sent after the last question (→ 15.3).
- **[Count votes] is inactive** → the poll is not stopped or has fewer than 10 complete
  polls → stop the poll; collect more votes (→ 15.6).
- **I cannot approve the count** → a question has fewer than 3 answers with at least
  4 points → in a standard poll, merge similar answers; if needed, resume voting
  (→ 15.6).

## 19.4 Problems during the game

- **The button to move on stays inactive for a long time** (for example [Start] after the intro) →
  the Display is minimised or open as a tab next to the control panel → open
  the Display in a separate window in full screen (TV, second monitor).
- **The game paused with a message about a missing device** → see 19.5.
- **The game ended after the settings were changed** → changing the settings during a game ends the current
  game → change the settings before the start or after the end; going to the guide and coming back
  does not interrupt the game (→ 16.1).
- **The game was not ended** → the control panel was closed without ending the game → always end
  the game with the [Finish game] button on the end screen (→ 17.5).
- **The board or sound lags in test mode** → all screens in one tab and frequent
  switching between tabs → test mode is for trying things out; for a real game, use separate devices
  (→ 17.1).
- **The game is waiting for sound from the Display** → each time the Display is opened, and after the browser mutes the page
  (for example, a TV gone to sleep), you need to unlock the sound again → press
  [Unlock sound] before the start and do not reload the Display during the game (→ 17.2).
- **[Done — start the game] is inactive** → the final does not have 5 questions → choose 5 final
  questions or random mode (→ 16.5.2).

## 19.5 Device problems

- **The game pauses every now and then, and a device shows as disconnected** → the phone
  with the buttons or the host tablet went dark or was switched to another app → keep the screen
  on for the whole game, plug the device into a charger, lengthen the automatic screen lock
  time and do not switch apps. If you use physical buttons or play without a host
  tablet, tick the matching option in the panel (→ 17.1). When you return to the page, the device
  reconnects on its own within a few seconds.
- **The QR code was scanned several times** → on the same phone, the newest tab works, and the older ones
  show a waiting message → go back to the same tab instead of scanning again; close any
  tabs you do not need.
- **"This device is waiting"** → the same device (buttons, host screen or
  Display) is open on another phone or in another browser → close that tab
  or wait a dozen or so seconds until it disconnects.
- **"Turn your phone sideways…"** on the buzzer → the buzzer works in landscape → turn
  the phone and switch off the screen rotation lock.
- **No sound** → the sound is not unlocked or the device is muted → check where the sound
  should come from (→ 17.2), the device volume and the volume in the settings summary.

## 19.6 Contacting support

At the bottom of every page there is a [Contact] button. In the "Contact us" window:

- "Your e-mail" — the reply will be sent to this address (filled in for you when you are signed in),
- "Subject" and "Message" — describe the problem,
- "Ticket number (optional)" — if you are writing about an earlier report,
  your message will be added to it,
- "Attachments" — up to 5 files of 5 MB each, for example screenshots.

After sending, you get a ticket number. To help solve the problem faster, write:

- what you were doing (on which page, step by step),
- what you expected and what happened,
- the text of the message, if one appeared — ideally with a screenshot,
- which device and which browser you were using.

# 20. Glossary

## 20.1 Game show terms

- **Bank (round pool)** — the total of the points revealed in a round; after the round it goes to the winning
  team (→ 3.4, 3.6).
- **Mistake (X)** — an answer that is not on the board, or no answer within 3 seconds (→ 3.5).
- **Final target** — the number of points the finalists must score together (→ 4.3).
- **Final** — the last stage: two finalists, five questions (→ 4).
- **Head of the family** — the team captain in the game show (→ 3.3).
- **Steal (taking over the points)** — after three mistakes, the opponents get one answer; a hit
  gives them the bank (→ 3.5).
- **Multiplier** — how many times the points from a given round count (→ 3.2).
- **Duel** — the start of a round: players from both teams compete for the right to play (→ 3.3).
- **Threshold** — the total score at which the game moves on to the final (→ 3.6).
- **Board** — the list of answers with points, revealed during a round (→ 2.2).

## 20.2 Poll and collaboration terms

- **Poll** — collecting answers from voters, which are turned into a board (→ 15).
- **Complete poll** — the vote of a person who answered all the questions; points are calculated
  from these (→ 2.4, 15.6).
- **Counting** — turning the votes into points before the poll is closed (→ 15.6).
- **Copy** — an independent copy of a game or logo, duplicated for yourself or sent to a friend
  (→ 6.6, 11).
- **Subscriber** — a person without an account whom you invite to polls by email (→ 14).
- **Sharing** — shared access to a question base or a device (→ 12, 17.1).
- **Task** — a poll invitation you have received (→ 15.4).
- **Invitation** — a request for a friendship, a subscription, access to a base or taking part in a poll.
- **Friend** — another person with an account whom you connected with through an invitation (→ 10).

## 20.3 Game and device terms

- **Question base** — a library of questions you can use again and again.
- **Host screen (Host)** — the device with the question and all the answers for the person
  reading the questions (→ 17.1).
- **Prepared game** — a game with answers and points entered by hand, without a poll (→ 7.1).
- **Community Games** — a public catalogue of ready-made games.
- **Logo** — lettering or an image shown during the game (→ 8).
- **Control panel** — the operator's page, from which the game is run (→ 17).
- **Buzzer** — a phone with the A and B buttons for the players (→ 17.1).
- **Draft** — a game still being prepared, not yet ready to play (→ 6.2).
- **Test mode** — all devices in one window, for trying things out (→ 17.1).
- **Display** — the board for the players and the audience, for example on a TV (→ 17.1).
